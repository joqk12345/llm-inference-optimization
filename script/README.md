# 出版格式生成脚本

本目录存放用于将书稿 Markdown 源文件转换为清华大学出版社 Word 格式的生成脚本。

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `generate_word.py` | 主脚本：读取项目根目录下的 Markdown 章节文件，生成符合出版社体例的 `.docx` 文件 |

---

## 使用方式

### 1. 安装依赖

```bash
pip install python-docx
```

### 2. 运行脚本

```bash
cd script
python3 generate_word.py
```

脚本会自动：
- 读取项目根目录下的 `preface.md`、`chapters/`、`appendix-*.md`、`docs/refs.md`
- 按正确顺序拼接内容
- 应用清华大学出版社的排版格式（字体、字号、行距、缩进等）
- 输出到 `../publish/manuscript.docx`

### 3. 打开 Word 后的手动操作

1. **更新目录**：在目录页右键 → 更新域 → 更新整个目录
2. **设置页码**：前言部分使用罗马数字，正文部分使用阿拉伯数字（分节符已插入）
3. **检查字体**：确保系统有 `宋体`、`黑体`、`Times New Roman`、`Courier New`

---

## 格式对照（清华大学出版社体例）

| 元素 | 格式 |
|------|------|
| 一级标题（第X章） | 三号黑体，居中 |
| 二级标题（1.1） | 小三号黑体，顶格 |
| 三级标题（1.1.1） | 四号黑体，顶格 |
| 四级标题（1.） | 小四号黑体，首行缩进两字符 |
| 正文 | 五号宋体 / Times New Roman，首行缩进两字符，1.5倍行距 |
| 代码块 | 小五号 Courier New，左侧缩进 |
| 表格 | 表头小五号黑体，内容小五号宋体，居中 |

---

## 输出位置

生成的待发布文件统一存放在项目根目录的 `publish/` 文件夹下：

```
publish/
  manuscript.docx          # 最新生成的完整书稿
  LLM推理优化实战_完整版.docx   # 历史版本（保留）
  LLM推理优化实战_清华格式.docx  # 历史版本（保留）
```
