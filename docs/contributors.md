# Contributor Hall of Fame

贡献通过 GitHub 提交、Pull Request、Issue 和评审记录追踪。本页暂未维护经核对的个人名单或排名，不展示占位人物、示例贡献和虚构统计。

## 如何参与

- 内容：纠正错误、改善解释、补充带来源和适用边界的案例。
- 代码：修复示例、补充可复现实验和有意义的回归检查。
- 反馈：提交章节位置、复现步骤与环境信息，帮助确认问题。

先阅读[贡献指南](../CONTRIBUTING.md)，再查看 [GitHub Issues](https://github.com/joqk12345/llm-inference-optimization/issues)。个人署名需核对贡献记录并确认展示意愿。

当前未公布 Pro 会员、咨询奖励、Discord 角色或固定活动安排；贡献认可依据实际记录维护。
