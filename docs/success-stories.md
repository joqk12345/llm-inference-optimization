# Reader Success Stories

本页收集读者的可复核实践。当前没有在此页发布经过核对的客户案例或社区统计；旧稿中的示例人物、收益数字和使用比例已移除。

## 提交案例

通过 [GitHub Issues](https://github.com/joqk12345/llm-inference-optimization/issues)提交，并说明是否同意公开署名和数据。不要上传凭证、用户请求或其他私有信息。

案例应包括：

- 问题与约束：业务目标、质量门槛、SLO、负载和预算。
- 环境：模型 revision、硬件数量与拓扑、精度、引擎版本和完整配置。
- 基线与候选：改变了哪个变量，使用了哪些章节的方法。
- 证据：命令、原始结果、失败记录、重复次数和统计方法。
- 结果与限制：质量、尾延迟、goodput、成本及不适用场景。
- 运营：工程投入、灰度、回滚条件和后续观察。

实验与 ROI 记录见[附录C](../appendix-c-benchmarks-roi.md)，可执行起点见[前缀缓存实验](../code/chapter10/README.md)。假设案例必须明确标注，不应包装成读者实绩。提交案例不附带会员或咨询奖励承诺。
