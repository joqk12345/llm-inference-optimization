# NVIDIA H100 产品规格

Source: NVIDIA, “H100 Tensor Core GPU.”  
URL: https://www.nvidia.com/en-us/data-center/h100/

Supports:

- H100 SXM、H100 NVL 等具体形态具有不同显存、带宽、功耗和互连规格。
- 峰值 Tensor Core 数字需区分精度、稀疏性与具体形态。

Does not support:

- 把“H100”当成单一规格，不区分 SXM、PCIe、NVL。
- 从峰值 TFLOPS 或 TB/s 直接推导某个模型的实际吞吐。
- 使用厂商跨代“最高提升”营销数字替代工作负载基准。
