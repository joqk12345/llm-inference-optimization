# GPTQ（2022）

Source: Elias Frantar et al., “GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers.”  
URL: https://arxiv.org/abs/2210.17323

Supports:

- GPTQ 是 one-shot weight quantization 方法，使用近似二阶信息逐层控制量化误差。
- 原论文使用校准样本获得层输入；因此不能写成“不需要校准数据”。
- 原论文的端到端速度数字绑定其 kernel、模型、GPU 与位宽设置。

Does not support:

- 将 GPTQ 展开为 “Gradient-based Post-Training Quantization”。
- 对任意新模型承诺固定精度损失或固定加速倍数。
- 仅凭量化算法名称判断生产可用性。
