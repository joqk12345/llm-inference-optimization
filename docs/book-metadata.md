# 书籍元数据

**最后更新**：2026-07-13

## 书名

- 中文主标题：LLM 推理性能优化
- 中文副标题：从原理到生产环境的性能优化实战
- English title: *LLM Inference Optimization: From Principles to Production*

## 定位

本书是一份面向工程实践的 LLM 推理系统指南。它把模型计算、GPU 资源、KV 状态、请求调度、低精度、服务部署和成本指标放在同一条分析链上。

核心特色：

- **机制导向**：先解释资源和数据流，再讨论优化方案；
- **系统视角**：同时考虑质量、延迟、吞吐、容量、可靠性和成本；
- **证据约束**：数字携带实验条件，关键论断指向来源卡；
- **可复现意识**：区分生产配置、实验骨架、伪代码与教学算例；
- **持续维护**：把版本敏感能力与相对稳定的原理分开管理。

## 目标读者

- 负责模型推理、服务性能或 AI 基础设施的工程师；
- 需要理解容量、SLO 与成本权衡的架构师和技术负责人；
- 希望从算法机制走向生产验证的研究者；
- 具备 Python 和基本机器学习知识、希望系统学习推理工程的开发者。

本书不是零基础的 Python 或深度学习入门，也不是某个框架的完整 API 手册。

## 内容结构

全书当前包含 11 章和 3 个主附录：

1. 动机与路径：第 1–2 章；
2. GPU、环境与推理机制：第 3–5 章；
3. KV、调度、量化与投机解码：第 6–9 章；
4. 生产部署与进阶架构：第 10–11 章；
5. 工具、排障与 benchmark/ROI 模板：附录 A–C。

准确目录以仓库根目录的 `SUMMARY.md` 为准；字数和节点数量以生成的统计文件为准，不在这里维护容易漂移的手工数字。

## 示例分类

书中代码使用以下标签语义：

| 类型 | 含义 | 发布要求 |
|------|------|----------|
| 可运行示例 | 面向明确版本和输入 | 依赖、命令和验证结果齐全 |
| 配置骨架 | 展示需要配置的维度 | 使用占位符，不宣称可直接生产使用 |
| 概念伪代码 | 解释机制或数据结构 | 不绑定私有内部 API |
| 教学算例 | 展示公式和决策过程 | 明确假设，不冒充实测数据 |

“有代码”不等于“已在所有环境验证”。版本、模型和硬件条件必须随示例一起阅读。

## 证据政策

- 论文和官方文档优先于二手总结；
- 论文性能数字只能在其模型、硬件、实现和负载条件内使用；
- 市场规模、成本趋势和企业案例必须有可追溯来源；
- 没有公开来源或授权的数据只能作为明确标注的教学算例；
- `latest`、nightly、浮动依赖和私有 API 不能作为生产可复现证据；
- 章节结论应记录假设、开放问题和失败边界。
